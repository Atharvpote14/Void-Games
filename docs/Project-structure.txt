Project Name:
Void Games

Project Type:
Full Stack Gaming Platform

Frontend:
React + Vite
Tailwind CSS
React Router DOM
Framer Motion
Axios
React Hot Toast
Lucide React

Backend:
Node.js
Express.js

Database:
Supabase PostgreSQL

Authentication:
Google OAuth (Supabase Auth)

Image Storage:
Cloudinary

Game Files:
TeraBox Share Links

Deployment:
Frontend -> Vercel
Backend -> Render
Database -> Supabase
