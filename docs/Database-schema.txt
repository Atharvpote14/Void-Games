Purpose
-------
Store users, games, categories, collections,
download links, comments, ratings, guides,
fixes, favorites, and analytics.

⭐ One improvement I'd make

Instead of storing categories directly in the games table as plain text, use foreign keys:

games.category_id
        ↓
categories.id

games.collection_id
        ↓
collections.id

This makes filtering much faster and avoids duplicate values like:

Action
action
ACTION

all being treated as different categories.
