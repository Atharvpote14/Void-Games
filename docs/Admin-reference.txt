⭐ One feature I'd add that most gaming sites don't have
Game Submission Queue

Instead of adding every game yourself, users can suggest games.

Flow
User

↓

Suggest New Game

↓

Admin Dashboard

↓

Pending Queue

↓

Approve

↓

Auto-create Draft

↓

Admin completes details

↓

Publish

The submission form could ask for:

Game Name
Steam URL (optional)
Official Website (optional)
Genre
Why they want it added
Additional notes

This helps you understand what users are looking for without promising that you'll provide copyrighted content. It also helps prioritize guides, fixes, or pages for popular requests.
