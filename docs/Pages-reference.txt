🔥 One major feature I'd add (better than most gaming sites)

I want Void Games to have a page that very few game download websites implement properly:

🎮 Game Status Page

Route:

/status

Users can instantly see:

🟢 Working Download

🟢 Installation Tested

🟢 All Mirrors Online

🟡 Mirror 2 Slow

🔴 Broken Link

🟢 Windows 11 Tested

🟢 Steam Deck Compatible

🟢 Controller Support

🟢 Multiplayer Working

🟢 Last Checked: 2 hours ago

Each game page would also display this status panel.

Why it's valuable

Many users visit download sites only to discover:

The link is dead.
The installer is outdated.
The crack/fix doesn't work.
No one knows if it works on Windows 11.

A clear status panel lets users know the current state before downloading and makes the site feel much more trustworthy.
